# Chevalier Caribbean Restaurant

Website for Chevalier Caribbean Restaurant — Haitian Caribbean cuisine, Black-owned and operated.
*Caribbean flavors made with love.*

661 Grant St, Camden, NJ 08102 · (856) 246-5932 · Open daily 10 AM – 9 PM
Order online: https://order.toasttab.com/online/chevalier-caribbean-restaurant-nj

## Files

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `logo.webp` — original logo
- `logo-full.webp`, `logo-emblem.webp`, `logo-light.webp`, `favicon.png` — web versions of the logo
- `menu.webp` — printable menu
- `griyo.webp` — griyo plate photo (Our Story)
- `*-thumb.webp` — dish photo thumbnails on the menu (griyo, poul fri, koden fri, ke bèf, legim)

## Preview locally

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173.
